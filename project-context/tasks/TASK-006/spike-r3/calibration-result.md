**关键观察（诚实声明）**：

1. **分离边际比 A/B 更差（-0.5667）**：LLM 把无关的"同事也养猫，推荐了一款猫粮"（S3-05，label=irrelevant）判成 0.7167 高分，同时把两条关键隐式关联正例判低——S1-04（养猫↔失眠，E001 同构）score=0.30、S5-05（养猫↔压力倾诉）score=0.15。**外部大模型同样未能建立"失眠↔橘猫"隐式关联的可靠分离**，且在"他人属性"（同事的猫）这类 hard 无关样本上反而给了最高分。
2. **temperature=0 下仍存在输出波动**：同一 prompt 三轮分数跳变，最大 vol=0.35（S2-02 鼻炎 ↔ 天气隐式关联：三轮 0.05/0.40/0.05），另有 S3-02 vol=0.20、S1-04 vol=0.20、S5-04 vol=0.30。波动 > 0.1 判据失效。
3. **关键门"通过"是假象**：best_grid thr=0.11 极低，R=1.0 靠"全保留"达成（fp=3），复现 R3 根因——F1=0.88 是"阈值选在重叠区 + 全保留"的假象，不是可靠分离。
4. **失败记录**：round 2 的 S5_other_attr 场景返回 judgments 长度 4 ≠ 候选数 5（模型漏判 1 条），标记 parse_mismatch，该轮该场景分数不采信。
