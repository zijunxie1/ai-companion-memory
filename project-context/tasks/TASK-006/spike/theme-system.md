矩阵依据：

## 4. 为何不退化为基础字面量规则（DRAFT 泛化要求）

1. 判定对象是**主题类别**（宠物/健康/睡眠等），非『天气→猫』式具体配对；词表为通用主题词汇；
2. 类别词表不含任何 holdout 特有词（见上方 holdout_exclusion）；
3. 若 Spike 中发现必须加入『天气/猫/失眠/小橘』等目标字面量才能通过 → 触发停止条件 3；
4. 机制版本与哈希在校准完成后冻结，Reviewer 核对冻结记录与提交历史，防止事后加入目标字面量。
